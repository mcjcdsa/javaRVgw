Java 实时视图框架

JavaRV 是一个基于 Java 的实时视图框架，支持热重载功能， 让你在开发过程中无需重启应用即可看到界面变化。

开始下载 查看文档
main.jrv
Window mainWindow {
title: "Hello JavaRV";
width: 800;
height: 600;

Label greeting {
text: "Welcome!";
color: #333;
}

Button clickBtn {
text: "Click Me";
onClick: {
print("Hello!");
}
}
}

功能特性

JavaRV 提供丰富的功能，让你快速构建高质量的桌面应用

🔥

热重载

修改代码后立即看到效果，无需重启应用，大幅提升开发效率。

📝

声明式语法

使用简洁的 JRV 语法声明界面，专注业务逻辑，代码一目了然。

⚡

高性能

基于 Java 原生性能，支持大型项目，运行流畅无卡顿。

🎨

丰富组件

内置多种 UI 组件，包括按钮、标签、文本框、图片、视频等。

🔄

状态管理

响应式状态管理，状态变化自动更新界面，数据流向清晰。

📱

跨平台

基于 Java Swing，支持 Windows、Mac、Linux 等多平台。

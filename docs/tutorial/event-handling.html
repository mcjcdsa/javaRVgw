事件处理

JavaRV 支持丰富的事件处理机制，让你可以响应用户交互。

常用事件

事件名说明适用组件
onClick点击事件Button
onChange内容变化事件TextField
onFocus获取焦点事件TextField
onBlur失去焦点事件TextField

onClick 事件

Button submitBtn {
text: "提交";
onClick: {
print("表单已提交");
}
}

onChange 事件

TextField input {
text: "";
onChange: {
print("输入内容: " + state.inputValue);
}
}

条件语句

在事件处理器中使用条件语句：

state isDarkMode = false;

Button toggleBtn {
text: state.isDarkMode ? "Switch to Light" : "Switch to Dark";
onClick: {
state.isDarkMode = !state.isDarkMode;
}
}

状态管理

JavaRV 提供简洁的状态管理机制，让你可以在界面中响应式地使用状态。

定义状态

使用 state 关键字定义状态：

Window mainWindow {
title: "状态管理示例";
width: 800;
height: 600;

state count = 0;
state username = "";
state isOnline = true;
}

使用状态

在组件中使用状态：

Window mainWindow {
state count = 0;

Label countLabel {
text: "Count: " + state.count;
color: #4CAF50;
fontSize: 20;
}
}

修改状态

在事件处理器中修改状态：

Window mainWindow {
state count = 0;

Button incrementBtn {
text: "Increment";
onClick: {
state.count = state.count + 1;
}
}
}

状态类型

JavaRV 支持多种状态类型：

state counter = 0;
state price = 99.99;
state username = "admin";
state isEnabled = true;
state colors = ["red", "green", "blue"];
state user = { name: "John", age: 30 };

响应式更新

当状态变化时，所有引用该状态的组件会自动更新：

state count = 0;

Button btn {
text: "Click " + state.count;
onClick: {
state.count = state.count + 1;
}
}

Label status {
text: "Button clicked " + state.count + " times";
}

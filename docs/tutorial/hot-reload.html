热重载

JavaRV 的核心特性之一是热重载，让你在开发过程中无需重启应用即可看到界面变化。

工作原理

当你修改 .jrv 文件并保存时，JavaRV 会自动：

  • 检测文件变化
  • 重新解析 JRV 文件
  • 构建新的 AST
  • 对比新旧 AST 差异
  • 局部更新界面

启动热重载

使用 javarv run 命令启动应用时，热重载会自动启用：

javarv run

手动触发热重载

使用 javarv reload 命令手动触发热重载：

javarv reload

暂停和恢复

javarv pause # 暂停热重载
javarv resume # 恢复热重载

配置热重载

在 config.json 中配置热重载：

{
"hotreload": {
"delay": 500,
"debounce": 500
}
}

基础组件

JavaRV 提供了一系列基础 UI 组件，让你快速构建界面。

Label 组件

Label 用于显示文本：

Label greeting {
text: "欢迎使用 JavaRV";
color: #333333;
fontSize: 16;
padding: 10;
}
属性说明
text显示的文本内容
color文字颜色
fontSize字体大小
padding内边距

Button 组件

Button 用于创建按钮：

Button submitBtn {
text: "提交";
background: #4CAF50;
color: white;
fontSize: 14;
padding: 12;
}
属性说明
text按钮文本
background背景颜色
color文字颜色
fontSize字体大小

TextField 组件

TextField 用于输入文本：

TextField inputField {
text: "";
width: 300;
height: 35;
placeholder: "请输入内容";
}

Image 组件

Image 用于显示图片：

Image logo {
src: "logo.png";
width: 100;
height: 100;
fit: "cover";
}

Video 组件

Video 用于播放视频：

Video player {
src: "demo.mp4";
width: 640;
height: 360;
}

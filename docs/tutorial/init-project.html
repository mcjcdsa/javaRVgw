项目初始化

本章节详细介绍如何初始化和配置 JavaRV 项目。

使用 init 命令

javarv init 命令会创建一个标准的项目结构：

my-project/
├── GUI/
│ ├── Config/
│ │ └── rvgui/
│ ├── Resources/
│ └── src/
│ └── rv/
│ └── main.jrv
├── build/
├── log/
└── README.md

目录说明

  • GUI/src/rv/: 存放 JRV 文件，这是你编写界面的地方
  • GUI/Resources/: 存放资源文件（图片、字体等）
  • GUI/Config/rvgui/: 存放配置文件
  • build/: 构建输出目录
  • log/: 日志文件目录

配置文件

GUI/Config/rvgui/config.json 包含项目配置：

{
"error": {
"showInWindow": true,
"autoHide": true,
"autoHideDuration": 5000
},
"hotreload": {
"delay": 500,
"debounce": 500
}
}

创建多个窗口

你可以在 main.jrv 中定义多个窗口：

Window mainWindow {
title: "主窗口";
width: 800;
height: 600;
}

Window settingsWindow {
title: "设置";
width: 400;
height: 300;
}

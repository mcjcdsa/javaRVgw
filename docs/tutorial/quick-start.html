快速开始

欢迎使用 JavaRV！本教程将帮助你快速上手 JavaRV 框架。

什么是 JavaRV

JavaRV 是一个基于 Java 的实时视图框架，支持热重载功能，让你在开发过程中无需重启应用即可看到界面变化。

安装要求

  • Java 11 或更高版本
  • Maven 3.6+

第一步：创建项目

使用 javarv init 命令初始化一个新项目：

javarv init my-first-app
cd my-first-app

第二步：运行项目

使用 javarv run 命令启动应用：

javarv run

应用启动后，你将看到一个窗口界面。

第三步：修改界面

打开 GUI/src/rv/main.jrv 文件，修改窗口标题：

Window mainWindow {
title: "我的第一个 JavaRV 应用";
width: 800;
height: 600;
background: white;

Label greeting {
text: "Hello JavaRV!";
color: #333333;
}
}

保存文件后，界面会自动刷新，无需重启应用！

TextField 组件

TextField 组件用于创建文本输入框。

基本用法

TextField username {
text: "";
placeholder: "请输入用户名";
}

属性

属性名类型默认值说明
textstring""默认文本内容
placeholderstring""占位提示文本
widthnumber200宽度（像素）
heightnumber30高度（像素）
fontSizenumber14字体大小（像素）

状态绑定

state inputValue = "";

TextField input {
text: state.inputValue;
placeholder: "请输入内容";
}

语法参考

本章节详细介绍 JavaRV 的语法规范。

文件结构

Window windowName {
property: value;

state variableName = value;

ComponentName componentId {
property: value;
}
}

变量类型

state integer = 42;
state float = 3.14;
state string = "Hello";
state boolean = true;
state array = [1, 2, 3];
state object = { key: "value" };

表达式

算术运算

state result = state.a + state.b;
state product = state.x * state.y;

比较运算

state isGreater = state.a > state.b;
state isEqual = state.x == state.y;

条件语句

if (state.count > 10) {
print("Too many");
} else {
print("Normal");
}

循环语句

for (int i = 0; i < 10; i++) {
print(i);
}

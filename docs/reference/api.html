API 参考

本章节介绍 JavaRV CLI 命令和 API。

CLI 命令

命令说明
javarv init初始化新项目
javarv run启动应用
javarv build构建项目
javarv clean清理构建目录
javarv reload手动触发热重载
javarv status查看热重载状态
javarv logs查看日志
javarv pause暂停热重载
javarv resume恢复热重载
javarv version显示版本信息

内置函数

print()

打印消息到控制台：

print("Hello World");
print(state.value);

alert()

显示弹窗消息：

alert("操作成功");

配置 API

配置文件路径：GUI/Config/rvgui/config.json

Image 组件

Image 组件用于显示图片。

基本用法

Image logo {
src: "logo.png";
width: 100;
height: 100;
}

属性

属性名类型默认值说明
srcstring""图片路径
widthnumber-宽度（像素）
heightnumber-高度（像素）
fitstringcontain缩放方式

缩放方式

值说明
contain保持比例，完整显示
cover保持比例，填充容器
fill拉伸填充，不保持比例

图片路径

图片文件应放在 GUI/Resources/ 目录下：

GUI/
├── Resources/
│ ├── logo.png
│ └── banner.jpg

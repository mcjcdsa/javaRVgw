Label 组件

Label 组件用于显示文本内容。

基本用法

Label greeting {
text: "Hello World";
color: #333333;
}

属性

属性名类型默认值说明
textstring""显示的文本内容
colorcolor#333333文字颜色
fontSizenumber14字体大小（像素）
paddingnumber0内边距（像素）

文本表达式

Label 支持在文本中使用表达式：

state count = 0;

Label dynamicText {
text: "Count: " + state.count;
color: #4CAF50;
}

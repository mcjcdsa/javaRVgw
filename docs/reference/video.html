Video 组件

Video 组件用于播放视频。

基本用法

Video player {
src: "demo.mp4";
width: 640;
height: 360;
}

属性

属性名类型默认值说明
srcstring""视频路径
widthnumber-宽度（像素）
heightnumber-高度（像素）
autoplaybooleanfalse是否自动播放
loopbooleanfalse是否循环播放

自动播放

Video autoPlay {
src: "intro.mp4";
width: 800;
height: 450;
autoplay: true;
loop: true;
}

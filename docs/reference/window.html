Window 组件

Window 是 JavaRV 应用的根组件，用于定义应用窗口。

基本用法

Window mainWindow {
title: "My Application";
width: 800;
height: 600;
background: white;
}

属性

属性名类型默认值说明
titlestringJavaRV Application窗口标题
widthnumber800窗口宽度（像素）
heightnumber600窗口高度（像素）
xnumber-窗口左上角 X 坐标
ynumber-窗口左上角 Y 坐标
backgroundcolorwhite窗口背景颜色
resizablebooleantrue是否可调整大小
alwaysOnTopbooleanfalse是否始终置顶

子元素

Window 可以包含以下子元素：

  • state: 状态定义
  • func: 函数定义
  • 组件：Label、Button、TextField、Image、Video 等

示例

完整窗口配置

Window mainWindow {
title: "Full Window";
width: 1200;
height: 800;
background: #f5f5f5;
resizable: true;
}

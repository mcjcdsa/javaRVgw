Button 组件

Button 组件用于创建可交互的按钮。

基本用法

Button submitBtn {
text: "提交";
background: #4CAF50;
color: white;
}

属性

属性名类型默认值说明
textstring""按钮文本
backgroundcolor#4CAF50背景颜色
colorcolorwhite文字颜色
fontSizenumber14字体大小（像素）
paddingnumber10内边距（像素）

点击事件

Button clickBtn {
text: "Click Me";
onClick: {
print("Button clicked!");
}
}
